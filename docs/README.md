# Project documentation

This folder presents the migration as a delivery case about behaviour, controls, and cutover readiness.

## Evidence map

1. [Project brief](project-brief.md) - the problem, scope, constraints, and definition of done.
2. [Migration design](migration-design.md) - the inventory, source-of-truth method, and rebuild protocol.
3. [Risk and decisions](risk-and-decisions.md) - idempotency, permissions, schedules, and rollback controls.
4. [Production evidence](production-evidence.md) - validated scenarios, defects found, and measured improvements.
5. [Close-out report](close-out-report.md) - lessons, handoff, and activation boundary.

The root [README](../README.md) is the executive summary. [architecture.md](../architecture.md) contains the expanded system model, and [privacy.md](../privacy.md) defines what is sanitized.
